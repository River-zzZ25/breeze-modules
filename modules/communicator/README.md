# Breeze Modules - Communicator

这是 `breeze` 中的上下位机/多机通信模块. 表现层采用 `RP-Proto`.

数据处理边界为: 原始流式数据 <--发送/接收--> model消息.

支持这几条通信链路:

- `vt`: 图传自定义数据块链路, 包括自定义客户端`MasterPilot` 以及工程的自定义控制器.
- `vision`: 视觉上位机(小电脑)
- `inter-robot`: 裁判系统多机通信链路

设计上, 每条链路各自实例化一个模块, 方便应用层自行做数据融合.

## 协议规定与解析设计

考虑到该传输链路可靠(USB CDC, 裁判系统多机通信, 图传自定义数据), 故不额外设计校验.

协议格式(小端):

```mermaid
flowchart LR
SOF[帧头: 8bit] --- LEN[包长度: 24bit] --- DATA[数据: 包长度byte]
```

这个协议非常简单, 可以设计状态机来搞. 不过我为了方便还是打算设计一个无状态流式解析来处理.
