# Breeze Modules - Models

这是 `breeze` 模块的 header-only 数据模型模块.

由于这个模块非常轻量, 且几乎在整个模块层通用, 故不设计开关.

## 开发指南

`Model` 层次开发具有以下要点:

- 几乎只编写结构体, 枚举, 以及constexpr转换函数.
- 可以在其他模块编写时, 一同编写本模块. 比如说在开发底盘模块时增加底盘相关 Model.
- 设计时需要注意不要假设任何东西, `Model` 的核心在数据表示, 不应该包含具体的功能实现.
- 对于有共同点而又有差异的模块, 建议先不进行抽象合并, 而是分别创建Model.

什么时候应该放对应的模块层, 什么时候应该放 Model?

应该放在Model:

- zbus消息类型.
- 跨模块共用的数据表示.
- 与任一模块都无关的通用辅助类型.
- ...

应该放在对应模块层:

- 模块层内部实现表示, 外部无需知道的类型.
- 暴露对象有限, 用于暴露给上级模块而非应用层的类型.
