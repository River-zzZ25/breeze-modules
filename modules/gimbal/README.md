# Breeze Modules - Gimbal

breeze 云台模块. 包含内容:

- HeightModule: 伸缩云台高度控制. 用于果冻车.
- YawModule: Yaw控制.
- PitchModule: Pitch控制.
- 组合模块: 方便应用层使用的模块组合, 包括:
  - LiftModule: 升降云台. 即高度控制+单Yaw
  - ...

## 设计思路

扩展 model 中对于反馈设备以及受控设备的数据定义, 然后将这些数据作为模块输入, 间接传递给算法层, 从而让模块与算法解耦.

模块层封装边界:

| 项目 | 内容 |
| 固定参数(构造函数) | 算法委托实现 |
| 输入 | 相关设备的数据, 控制指令 |
| 输出 | 控制状态等等 |
